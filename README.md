## 🛡️ Система защиты — как это работает

AnimeFlash использует многоуровневую защиту для обеспечения безопасности пользователей.

### Уровень 1 — Проверка целостности файла (HMAC-SHA256)

```
При сборке:
  build.py  →  вычисляет HMAC-SHA256 от AnimeFlash.exe
            →  сохраняет подпись в .fluxion_sig

При запуске:
  eula_guard.py  →  считывает .fluxion_sig
                 →  пересчитывает HMAC-SHA256 от запущенного .exe
                 →  сравнивает: если не совпадают → БЛОКИРОВКА
```

**Что это даёт:**
- Если кто-то изменил `.exe` (добавил вирус, убрал защиту, перепаковал) — HMAC не совпадёт
- Файл `.fluxion_sig` нельзя подделать без знания секретного ключа Fluxion Team
- При каждой официальной сборке создаётся новая уникальная подпись

### Уровень 2 — Онлайн верификация (опциональная)

```
eula_guard.py  →  отправляет на api.fluxionteam.ru: { version, анонимный ID устройства }
               →  сервер отвечает: blocked: true/false
               →  если заблокировано → предупреждение + закрытие
```

- Позволяет заблокировать скомпрометированные или устаревшие версии
- Анонимный ID устройства — только хеш, **не содержит личных данных**
- При недоступности сети — проверка пропускается (offline-friendly)

### Уровень 3 — EULA (Лицензионное соглашение)

При первом запуске показывается лицензионное соглашение. Пользователь должен прокрутить его до конца и нажать **«Принять»**. Без этого программа не откроется.

Статус принятия хранится в: `~/.animeflash/eula_accepted.json`

### Защита от обхода

| Метод атаки | Защита |
|-------------|--------|
| Замена `.exe` на модифицированный | HMAC не совпадёт → блок |
| Удаление `.fluxion_sig` | Программа не запустится без подписи |
| Подделка `.fluxion_sig` | Невозможно без секретного ключа |
| Репак с торрента | Изменение файла → HMAC сломан |
| Старая скомпрометированная версия | Онлайн верификация заблокирует |
